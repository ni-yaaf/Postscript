# POSTSCRIPT

*A place for words.*

> *"Some words deserve more than a comment."*

POSTSCRIPT is a private digital writing desk and public reading room designed for composing long, thoughtful letters in response to posts—and sharing published letters individually through clean, permanent links without accounts, subscriptions, databases, or paid servers.

---

## What POSTSCRIPT Is

POSTSCRIPT separates two quiet spaces:

- **The Writing Desk (Private):** Stored locally in your browser (`localStorage`). Here you paste a post for reference, write long-form formatted letters, save favourite passages, organize themes, and manage drafts.
- **The Reading Room (Public):** A calm, distraction-free reading experience hosted for free on **GitHub Pages**. Only letters you explicitly package and commit to GitHub appear publicly.

Everything runs **100% free** with zero API keys, zero accounts, and zero paid services.
